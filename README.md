# Parallax Studio

An intelligent research operating system focused on structured knowledge, evidence provenance, discovery, and long-form synthesis.

### Technology

`TypeScript` · `React` · `PostgreSQL` · `Firebase` · `Local AI`

Parallax is designed to help researchers preserve source knowledge, organize evidence, discover meaningful relationships across large bodies of information, and carry durable research context into long-form outputs.
